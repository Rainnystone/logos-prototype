## Purpose

This file records the decisions already made for `gossipelog agent` so later
discussion does not lose its foundation when context becomes compressed.

This is not the main design document. It is the running memory of what has
already been decided, what remains open, and where later changes need to be
made deliberately instead of accidentally.

## Usage Rules

Use this log with the design document, not instead of it.

Rules:

- record only confirmed decisions in the main decision table
- record unresolved items in the open question table
- do not silently upgrade an open question into a decision
- if a decision changes later, add a new row rather than rewriting history
- keep each row short enough to scan quickly during implementation planning
