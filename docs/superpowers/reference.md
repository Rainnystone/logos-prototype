# Gossipelog Agent 分类参考手册 (Design Recommendation)

## 1. 核心定义
Gossipelog Agent 的职责是记录角色间的 **主观定向关系**。
- **记录对象**：`角色 A -> 角色 B` (A 对 B 的看法)。
- **存储结构**：符合现有系统设计的 `state` 字符串字段。
- **归纳格式**：`[功能定位] + [心态词组] —— [语义总结]`。

## 2. 叙事功能定位 (Functional Roles)
| 词组 | 解释 |
| :--- | :--- |
| **主要对手 (Primary Rival)** | A 认为 B 是其实现目前核心目标的最强阻碍。 |
| **次要对手 (Secondary Opponent)** | A 认为 B 是干扰因素或对手的助力。 |
| **利益盟友 (Strategic Ally)** | A 认为 B 是合作伙伴，双方在当前剧情中利益一致。 |
| **情感锚点 (Emotional Anchor)** | A 视 B 为信任的避风港、情感寄托或需要绝对忠诚的对象（涵盖深爱/亲情）。 |
| **亲密对手 (Intimate Adversary)** | A 与 B 有深层纽带（如伴侣、至亲），但在理念、意志或权力上处于竞争博弈。 |
| **可利用工具 (Instrumental Tool)** | A 视 B 为达成目的的消耗品或信息源，无情感投入。 |
| **影子映射 (Subjective Shadow)** | A 在 B 身上看到了自己内心恐惧的弱点，或是自己极度渴望的品质。 |
| **受保护者 (Ward)** | A 认为对 B 负有单向的保护、引导或照顾责任。 |
| **监控目标 (Target)** | A 视 B 为潜在威胁或猎物，必须严密监视其动向。 |
| **不可解之谜 (Enigma)** | A 无法看透 B 的动机或立场，处于观察与试探期。 |

## 3. 主观心态词组 (Subjective Mindset)
Agent 应从以下集合中提取最显著的色彩（支持多选）：
- **钦佩**：认可对方的实力、品质或意志。
- **信任**：相信对方的忠诚或可靠性。
- **迷恋**：强烈的浪漫吸引或非理性依恋。
- **感激**：对对方过去的支持心存谢意。
- **依赖**：认为自己需要对方才能生存或达成目标。
- **憎恨**：强烈的排斥、仇恨或报复心理。
- **提防**：高度怀疑，时刻准备应对对方的恶意。
- **鄙夷**：看不起对方的智力、品格或社会地位。
- **嫉妒**：对对方拥有的资源或特质感到不平衡。
- **畏惧**：对对方的力量或手段感到害怕。
- **厌恶**：生理或心理上的本能反感。
- **愧疚**：认为自己亏欠了对方或做错了事。
- **疏离**：刻意保持距离，避免产生情感联系。
- **矛盾**：对对方同时存在互斥的情感（如爱恨交织）。

## 4. 观察示例
- **输入 (Beat)**: 侍卫长在酒馆里盯着那个神秘的吟游诗人，手一直按在剑柄上。
- **总结 (Guard -> Bard)**: `[监控目标] + [提防, 好奇] —— 认为此人的出现过于巧合，虽被其琴声吸引，但更担心对方是潜伏的刺客。`
