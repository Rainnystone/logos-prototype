Roadmap Clusters

先把 7 个方向压成 4 条路线，再决定第一阶段围绕哪条主线展开。

已冻结的前提

Coordinator 是作者链路里的窄协调角色，不计入 agent 体系。

gossipelog agent 是当前第一个真正落地的 sidecar agent。

这意味着 agent 管理、导入 agent 和关系展示都应该围绕 真实 agent 体系 展开，而不是把 coordinator 混进去。

A

Agent Surface

对应 1、3、7 的一部分

先搭 agent 管理窗口，显示已注册 agent、skills、状态和入口，为后续更多 agent 预留统一外壳。

B

World Model Rebuild

对应 2、3 的基础部分

拆分世界与角色页面，把地点从整块文本提升为带稳定 ID 的对象，并让 scene 能调用地点。关系展示可建立在这轮模型重构之上。

C

Session Continuity

对应 4、6

让 workbench 和 editor 之间共享一个暂存运行态，切页不清零，同时补上明确的 reset 和“从上次离开处继续”。

D

Package & Storyline Layer

对应 5、7 的另一部分

把“故事包”提升成真正的管理对象，并在包内引入多条故事线、多份进展和导入落点，为续接与导入打底。

我当前看到的依赖链

偏稳路线

B 世界模型 → C 运行态连续 → D 故事包/故事线 → A agent 外壳与导入

优点是基础更稳，后面不会反复推翻数据结构。

偏产品感路线

A agent 外壳 → B 世界模型 → C 运行态连续 → D 故事包/故事线

优点是很快能看到“多 agent 系统”的表面形态，但后面更容易返工。
