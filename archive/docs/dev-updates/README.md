# Dev Update Archive

这里存放按“整轮开发更新”封板归档的文档集合。

和 `archive/docs/superpowers/` 不同，这里的归档不是零散的单篇 spec / plan 退役，而是把同一轮开发更新对应的：

- phase 级 spec / implementation plan
- phase 工作记忆
- 根目录恢复快照
- 必要的视觉参考与过程材料

一起按一组档案保存下来。

## 当前已归档更新

- [March Dev Update](march-dev-update/README.md)

## 使用原则

- 如果任务是继续做“当前活跃工作”，优先看根目录 `task_plan.md`、`progress.md`、`findings.md` 与 `docs/codemaps/`。
- 如果任务是回看已经封板的一整轮更新，再进入这里对应的更新目录。
- 这里的内容用于解释“当时怎么设计、怎么实现、怎么验证”，不作为下一轮工作的默认执行入口。
