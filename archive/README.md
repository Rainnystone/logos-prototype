# Archive

这里集中存放当前仓库里与代码实现、测试执行、运行入口无直接耦合的记录型材料。

包含内容主要有两类：

- `archive/docs/`
  设计稿、实施计划、重构记录、UI/UX 交接材料、历史说明文档。
- `archive/vendor/LOGOS-SPEC/`
  过去整理进仓库的 LOGOS 规格快照、契约文档、作者工作流说明、历史 ADR 与样例材料。

其中 `archive/docs/superpowers/` 专门存放已经不再作为当前执行依据、但仍需要保留以便回看和追溯的历史 plan、spec 与相关草稿。

## 使用说明

这些内容现在统一视为归档记录和参考材料。

它们可以帮助理解历史背景、设计演变和过去的约束来源，但它们**不是**当前仓库里的最高优先级“圣经”，也**不是** coding agent 在新任务里必须机械服从的唯一依据。

当前仓库里真正的优先级仍然是：

1. 人类在当前对话里的直接要求
2. 当前分支已经落地的代码与测试行为
3. 这里的归档记录

如果归档文档和当前任务冲突，应先确认人类意图，再以当前实现与测试为准，而不是把归档内容当成不可推翻的主规范。
